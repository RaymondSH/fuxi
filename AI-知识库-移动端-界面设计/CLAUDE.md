# Atlas 项目规范

## 目录与命名

- Web 页面保留现有根目录文件，不因移动端工作重构。
- 移动端页面使用 `ios-*.html` 与 `android-*.html` 命名，每个用户界面独立成文件。
- 移动端共享样式与交互分别放在 `mobile.css`、`mobile.js`。
- `mobile.html` 仅作为移动端页面入口，不承载完整产品界面。

## 视觉与内容

- 延续 `styles.css` 中 Atlas 视觉令牌：翡翠绿表示同步/索引，紫色仅表示 AI。
- 用户可见文案使用简体中文；代码、变量名和文件名使用英文。
- 不编造产品指标；缺失数据使用 `—` 或明确状态。
- 移动端必须重组信息层级，不直接缩放 Web 页面。

## 交互与验证

- iOS 点击目标不小于 44px，Android 点击目标不小于 48px。
- 输入、搜索、筛选、编辑、保存等动作必须可操作。
- 每次修改后检查 HTML 结构、页面链接、交互脚本和移动端溢出。
- 不修改 `.env`、密钥、CI/CD 或数据库结构。
