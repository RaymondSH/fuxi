关键设计决策

导航 & 信息结构

顶层只有 4 条主路径——主界面、搜索、知识图谱、所有笔记——加一个固定可见的 ⌘K 命令栏。搜索和图谱是对等的两个浏览器而不是"图谱藏在 power user 菜单里"。这呼应你选的两种主交互。

侧栏用印刷感的小型 mono 来标记 SECTION、计数和快捷键。这是 tech-utility 视觉系统里最强的"密度即信息"信号。

AI 始终带"出处"

所有 AI 生成内容用左侧紫色细条 + 紫色小标的方式包裹，引用以 mono 数字 chip 12 的形态嵌入正文，hover/click 跳转到原始来源卡片。这一处理同时表达了两件事：

  • AI 内容和人工笔记视觉上可区分，避免污染你的真实记录。
  • 引用永远是一等公民——这是个人知识库相比通用聊天产品的核心差异化。

检索 = BM25 + 向量 + AI 答复

搜索页同时展示「Atlas 答复」「原始命中（带 BM25 / 向量 / 混合分）」「时间直方图」三层。让你能从"我要个答案"到"我想自己看一遍命中"无缝切换。

每个命中显示三个分数，是 power user 的可观测性，也是产品对 AI 答案可信度的承诺。

图谱不止是装饰

图谱页里三种边、AI 推断关系单独着色，节点 inspector 还会列出"建议的下一跳"——比如"与 agentic memory 集群桥接 +3 个潜在连边"、"合并候选：2 个标题近义的草稿"。让图谱从"漂亮的星座"变成一个可操作的知识库管家。

笔记 = 阅读 + 编辑 + 询问 一体

正文用衬线 (Source Serif 4) 拉开阅读感，wikilink 用紫色 underline-block 而不是蓝色超链接；callout、blockquote、代码块都是真实组件。右侧 AI 助手默认"上下文 = 本笔记"，可一键扩展到"反向链接 / 整个标签"。

设置页把抽象的东西具体化

"索引状态"放在顶部，4 个 mono 大数字 + 进度条，从"系统设置"变成"系统体检"。模型选择是 4 张卡片含 token 计价。隐私一栏有"在提问前显示将发送的内容"这种可执行开关，而不是一段法律免责声明。

视觉系统

调色板

  • --bg 页面底层
  • --surface 卡片 / 模块
  • --fg 正文 / 强对比
  • --accent · emerald 同步 / 索引 / OK
  • --ai · violet AI 生成内容
  • --warn 待办 / 需修复

字体与排版

UI 使用 Inter / 系统 sans，搭配 JetBrains Mono 承载所有「ID/路径/计数/相似度/快捷键」——这是 tech-utility 的灵魂。笔记正文换成 Source Serif 4 拉开阅读感。所有数字使用 font-variant-numeric: tabular-nums，对齐密度。

三档字重：450（正文）、510（UI 标签）、590（标题）。从不使用 700+ 的 bold。

克制 & 节奏

整套设计严格遵守"每屏 ≤ 2 处 accent 使用"。强调色专属于"已索引/同步"这类语义化状态；AI 紫专属于 AI 生成内容；其他一律是中性灰阶。没有渐变背景、没有 emoji 功能图标、没有左侧色条圆角卡片这种 AI 套版。
