Sparse autoencoders 的层级语义提取

把 SAE 看作"字典"在浅层成立，但深层不成立——可解释性更像一段语义在一组特征上的电路。

过去两个月里我在思考一个问题：为什么在我们这些[[mechanistic-interpretability]]的实验里，[[sparse-autoencoders]] 在浅层"漂亮极了"，到了深层却越来越难复现单义特征？综合 Anthropic 的 monosemanticity 报告1、Nanda 的残差分解2、以及我自己跑出的两个对比实验，我得到的工作假设是：

SAE 不是一个统一的字典。它在浅层是字典，在中层是组合空间，在深层是电路。这三档对应不同的可解释性范式，混用一个评估方法是错的。

三档可解释性

浅层 (layers 1–4)：原子特征

这一段最像"字典"：每个 feature 大致对应一个词性触发器、token 模式或简单的语义类别。Anthropic 的初代结果就停在这一层，它非常自然地把可解释性等同于单义性 (monosemanticity)。我自己在 Pythia-2.8B 的 layer 3 上观察到，top-2048 个 feature 的下游 attribution 几乎是稀疏 one-hot 的。

中层 (layers 5–16)：组合性

这里开始出现"概念向量加法"——同一个 feature 在多个语义场景里被激活，并且它的方向可以与其他 feature 做线性组合得到一个新的"组合概念"。这正是 Nanda 的残差分解描述的现象2。在这一层用"字典"做评估是误导的：feature 的可解释性不取决于它自己，而取决于它与谁组合。

深层 (layers 17+)：电路语义

到了 layer 22 之后，单一 feature 的下游 attribution 不再稳定。但前 3 个 feature 的线性组合能稳定预测——这恰好是"电路 (circuit)"的味道3。换句话说：在深层，"可解释性"的载体不再是节点，而是子图。

"Dictionary learning recovers interpretable features at scale, but our preliminary work suggests that features at deeper layers may be more polysemantic, hinting at circuit-level structure." — Toward Monosemanticity (update), transformer-circuits.pub

我的实验

我在 pythia-2.8b 上跑了一组对照：分别在 layer 3 / 12 / 22 训练同样配置的 SAE，对 256 个 promp t 测量"单 feature 的下游 attribution 稳定性"。结果用一组指标可以总结为：

layer  expl-var  mono-rate  top1-stable  top3-stable
 3       0.71      0.93        0.88          0.94
12       0.74      0.61        0.42          0.79
22       0.69      0.34        0.14          0.71

top1-stable 急剧下降但 top3-stable 维持得很高——这正是上面那条"深层是电路"的证据。值得注意的是 explained variance 几乎没变，说明 SAE 本身在"学到东西"，只是这些东西不再用单一节点的方式表达。

与现有工作的关系

  • Anthropic monosemanticity：在浅层成立，描述了"字典假说"的下限。
  • Nanda residual decomposition2：中层组合性最干净的形式化。
  • Decode (Jul 2025)4：在 70B 上看到组合性"出现得更早"——可能是规模诱发，与我的小模型结果一致地表明分层结构存在，只是分层位置在更大的模型上前移。

待解决的问题

  1. SAE 的 width / sparsity 是否会改变这三档的分布？([[sae-width-study]] 起草中)
  2. 能否用 [[circuit-extraction]] 工具自动找到"top-k 组合特征"作为可解释单元？
  3. 这套分层假说是否也适用于 vision tower / multimodal？
